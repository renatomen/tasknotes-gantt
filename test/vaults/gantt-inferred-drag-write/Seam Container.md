# Seam Container

A fully authored, deliberately roomy parent for `Seam Only`. It exists so the seam
drag can be observed at TWO placements — a note renders both at top level and under
its parent, and a single-placement note cannot show a missed mirror.

Its window is wide enough to hold any span the seam drag derives, which keeps the
ancestor cascade out of the picture: the journey under it is about the echo
reaching every placement, not about what a parent does when a child outgrows it.
